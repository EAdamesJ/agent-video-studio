# Security policy

## Supported versions

Security fixes target the latest version on the `main` branch. The project is in pre-release development; no stable release line is supported yet.

## Reporting a vulnerability

Do not open a public issue with credentials, private media, or exploit details. Use GitHub's private vulnerability reporting for this repository when available. Include affected versions, steps to reproduce, impact, and a safe way to contact you.

The application is designed for a single local operator. Keep the web/API/MCP endpoints on loopback unless a trusted gateway provides TLS, authentication, and access controls.
